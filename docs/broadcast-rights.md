# 2026-27 赛季中国大陆正版观看渠道（查证记录）

查证日期：2026-10-16。这份记录对应 `packages/data/config/broadcast.json`，页面「去哪看」里显示的就是那个配置。
**改配置不需要写代码**：直接在 GitHub 网页上编辑那个 JSON 文件即可，下一次数据管线运行就会生效。

## 查证方式与局限

- 云端环境无法直接打开国内网站，所有结论来自搜索引擎结果摘要（官方页面、通讯社、行业媒体）。
  「已核实（high）」= 联赛/欧足联/国际足联等**官方来源**在搜索结果中这样写，且有其他报道佐证；并不代表逐页打开确认过。
- 搜索额度用完前，**国王杯、西班牙超级杯、英格兰联赛杯、2026 洲际杯**没有查到版权方，配置里标为「待核实」。
- 各平台的**回放规则**（有没有全场回放、保留多久、是否需要会员）基本都没能核实，需要你在 App 里看一下。
- 下面所有来源都刻意避开了标题或链接里带比分、冠军的页面。
